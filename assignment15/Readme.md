# Online Exam Evaluator with Negative Marking

A simple Java console-based application that evaluates an online exam by comparing the correct answers with the student's responses. The program applies positive marks for correct answers, negative marking for wrong answers, and zero marks for unattempted questions.

## Project Overview

The Online Exam Evaluator is a Java program designed to evaluate a student's exam answers.

The program stores the correct answers and student answers in separate character arrays. It compares both arrays question by question and calculates the final score according to the given marking scheme.

The application also counts the number of correct, wrong, and unattempted questions.

## Objectives

The main objectives of this project are:

1. Store correct answers in a character array.
2. Store student answers in another character array.
3. Compare both arrays position by position.
4. Apply negative marking for incorrect answers.
5. Identify unattempted questions.
6. Count correct, wrong, and unattempted answers.
7. Calculate and display the final score.
8. Format the final score to one decimal place.

## Marking Scheme

| Outcome | Marks |
|---|---:|
| Correct Answer | +2 |
| Wrong Answer | -0.5 |
| Unattempted | 0 |
