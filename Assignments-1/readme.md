# Assignment 1 - Student Profile and Basic Calculator

## Java Fundamentals

A simple Java program that collects **student information** and performs **basic arithmetic calculations** on two numbers.

---

## Assignment Details

This project is part of the **Java Fundamentals** assignment.

The program demonstrates basic Java concepts such as:

- Variables and Data Types
- User Input using `Scanner`
- Arithmetic Operators
- Conditional Statements
- `if-else`
- Basic Input and Output

---

# Features

## Student Profile

The program accepts the following student information:

- Student Name
- Roll Number
- Year

After taking the input, the program displays the student's profile.

---

## Basic Calculator

The program accepts two numbers and performs the following operations:

- Addition
- Subtraction
- Multiplication
- Division
