# Assignment 5 - Hotel Room Booking System

## Java Fundamentals

A simple Java program that manages hotel room bookings using Object-Oriented Programming concepts.

---

# Assignment Details

This project is part of the **Java Object-Oriented Programming** assignment.

The program allows users to manage hotel rooms and perform booking operations.

---

# Features

## Room Management

The program stores:

- Room Number
- Room Type
- Customer Name
- Number of Days
- Price Per Day
- Booking Status

---

## Room Booking

The user can:

- Book a room
- Enter customer details
- Select number of days
- Check booking status

---

## Room Operations

The program provides the following operations:

- Book Room
- Display Room Details
- Calculate Bill
- Check Booking Status
- Cancel Booking
- Display Total Bookings
